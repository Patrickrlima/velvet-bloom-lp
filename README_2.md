# Velvet Bloom — Flores & Presentes

Landing page da Velvet Bloom (Imbé, Litoral Norte do RS). É um único arquivo HTML autossuficiente — todas as imagens e o vídeo já estão embutidos dentro do `index.html`, então não existe nenhuma outra pasta ou dependência para subir junto.

## Como publicar no GitHub Pages

1. **Crie o repositório**
   No GitHub, clique em **New repository**. Dê um nome (ex: `velvet-bloom`) e deixe como **Public** (o GitHub Pages gratuito exige repositório público, a menos que você tenha um plano pago). Não marque nenhuma opção de inicialização (README, .gitignore etc.) — vamos subir os arquivos prontos.

2. **Suba os arquivos**
   - Pelo **GitHub Desktop**: clone o repositório vazio, copie o `index.html` (e este `README.md`, se quiser) para dentro da pasta clonada, e faça o commit + push.
   - Ou pelo **site do GitHub**: dentro do repositório recém-criado, clique em "uploading an existing file" e arraste o `index.html`.

3. **Ative o GitHub Pages**
   No repositório, vá em **Settings → Pages**. Em "Source", escolha a branch `main` e a pasta `/ (root)`. Salve.

4. **Aguarde e acesse**
   Em 1–2 minutos o GitHub publica o site. O link fica no formato:
   `https://SEU-USUARIO.github.io/velvet-bloom/`

   Esse link já mostra a página inicial automaticamente, porque o arquivo se chama `index.html`.

## Atualizando o site depois

Sempre que precisar mudar algo, é só substituir o `index.html` do repositório pelo novo arquivo e o GitHub Pages atualiza sozinho em 1–2 minutos.
